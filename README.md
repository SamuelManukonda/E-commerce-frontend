# E-commerce-frontend

Simple React + Redux + Material UI e-commerce catalogue.

## Features

- Product data loaded from `public/products.json`
- Global state managed with Redux Toolkit
- Responsive product grid with Material UI
- Pagination for the product list

## Scripts

- `npm start` – run the app in development mode
- `npm test` – run the test suite
- `npm run build` – create a production build
